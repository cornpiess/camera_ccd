# Camera 18 风格升级与双列卡片

## 实现依据

参考 [Dazz/Gloam 一手资料整理](./Dazz-Gloam风格参考.md)。本轮采用独立色彩性格，不声称获得或复制竞争产品私有配方。

生产 LUT 编译路径原来将整个 `color.hueBands` 当成单个分区读取，没有索引分区名称，因而七分区参数全部退回中性值。已修复，这是理光负片等预设辨识度不足的一个确定原因。

## 统一管线 v3

共享预览 / 成片：LUT 强度 → 色温与 tint → 饱和度 → 七分区 HSL → 分离明暗染色 → 曝光 / 对比 / 黑位 / 五点曲线 → 暗角。

分离染色 `color.splitTone.shadows/highlights` 是三个 RGB 偏移值，限定 ±0.12。通过平滑亮度权重减少纯黑 / 纯白染色，对暖肤色区域降低染色权重；偏移减去自身亮度分量，避免用染色顺便压暗。色彩阶段仍预编译进单个 cube，无新增逐帧色彩滤镜。无 LUT 的导入配置也走同一编译链路；真正中性配置跳过 cube。

仅成片：deharsh、单色柔光颗粒。颗粒使用 Apple 的 `CIRandomGenerator`、`CIColorMatrix`、`CISoftLightBlendMode`；暗角用 `CIVignetteEffect`。[Apple Core Image Filter Reference](https://developer.apple.com/library/archive/documentation/GraphicsImaging/Reference/CoreImageFilterReference/)

颗粒与暗角按图像尺寸归一化，零强度跳过。ORIG 保持原始数据直通；共享 CIContext、后台串行处理队列、拍摄 Promise、物理镜头与光圈控制均保持原有职责。没有添加假景深、假光斑或品牌原生分支。

## 配方方向

| 模式 | 方向 | 推荐光圈 |
| --- | --- | --- |
| GRIT P | 鲜红、黄绿、清晰反差 | ƒ/2.8 |
| GRIT N | 蓝绿、柔红、柔和亮部 | ƒ/2.8 |
| SKIN C | 蜜桃肤色、温润高光 | ƒ/1.8 |
| CC | 低饱和、沉稳蓝、青灰暗部 | ƒ/4 |
| NC | 暖亮部、深绿、浓红、较可见颗粒 | ƒ/2.8 |
| M-RF | 浓红、厚实反差、克制 CCD 纹理 | ƒ/1.8 |
| V-MF | 保留原有 VMF LUT 和细腻自然路线 | ƒ/2.5 |
| ORIG | 零风格处理 | 无推荐值 |

双列卡片展示：稳定名称 / 风格标题 / 色彩描述 / 适用场景 / 推荐光圈，配合选中边框与光圈图形。小屏与放大字体下优先保留文字和光圈数值。PRO 标记、试拍计数、测试设置门、中英文和法务入口保留。

## 验证边界

- 离线回归覆盖实际 TypeScript 导入校验、旧配置兼容、5832 个有界 RGB 探针、ORIG 精确直通、肤色通道顺序、正负片绿植色相差异，以及 GRIT N 相对原图的最低变化量。
- tone-audit 补齐原来遗漏的 HSL 和分离染色，用亮度而非单个红通道检查灰阶；曲线和 LUT 插值属于 CPU 近似，颗粒、暗角、Core Image 工作色域和最终编码仍需真机核对。
- 三个尺寸 / 语言组合通过静态组件布局与卡片 / PRO 回调检查。桌面预览使用 React Native 组件的 DOM 适配，仅用于排版；不代表 iOS Liquid Glass 材质、VoiceOver 或动画验收。
- `npm run prepackage` 全部步骤通过。现有 ApertureBar hooks 警告属于之前挂起项，本轮没有修改。Swift 语法 / 类型待 CI 构建验证；成片审美与新阶段的性能待普通 iPhone 真机验证。没有触发构建。

已保存的调色 override 优先于内置配方，不会被本轮自动覆盖。测试新配方时请备份后恢复内置值。
