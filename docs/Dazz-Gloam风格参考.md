# Dazz / Gloam 风格参考

研究日期：2026-10-09。用户输入的「glaom」按 Gloam 相机理解；已通过开发者网站与 App Store 的开发者描述确认产品。只使用一手资料；下文的配方与卡片建议属于 Camera 18 的设计推导，不是竞争产品的私有参数或界面复刻。

## 可核实的参考方向

- **Dazz**：开发者强调即时直出，以及从胶片样本提取颜色与纹理；同时提供胶片、便携数码、CCD 等不同相机类型。因此风格差异应来自颜色与影调组合，而不是统一套上同一颗粒或暗角。[Dazz 官方 App Store](https://apps.apple.com/us/app/dazz-cam-vintage-camera/id1422471180)
- **Gloam**：T3 强调胶片扫描色彩；CCD12 强调浓郁的油画色彩与柔和影调；GRD 提供正片、负片与黑柔；U2 强调自然随拍。可借鉴的是各相机清晰的审美定位与适用场景。[Gloam 官方 App Store](https://apps.apple.com/cn/app/gloam-%E7%9B%B8%E6%9C%BA/id6753741715)
- Gloam 开发者网站也将产品定位于电影感、复古胶片色调、人像及街拍，而不是只追求强烈破坏画质。[Gloam 开发者网站](https://gloam-image.com/)

## 理光负片的直接依据

理光官方展示相同参数下正片与负片的区别：负片红色偏褪色朱红，蓝色更低饱和，绿色明显偏蓝且更深；正片的绿色偏黄、红色更鲜明。官方文章提供的是个人自定义示例，并非统一默认配方。[理光官方：Customize Negative Film](https://www.grblog.jp/en/article/7151/)

**设计推导**：GRIT N 应突出蓝绿、柔和朱红、低饱和蓝与柔和高光；GRIT P 则以鲜明红色、偏黄绿、较强中间调反差形成对照。两者都只加全局暖色或微弱 LUT，会削弱用户感知到的区别。实现时先核对实际 LUT 与 hue-band 叠加后的结果，再确定强度，避免重复偏色。

## 8 个预设的差异化建议

以下是 Camera 18 建议方向，不声称精确还原 Dazz、Gloam 或实体相机。

| 预设 | 首要可见特征 | 建议卡片描述 | 适用场景 |
| --- | --- | --- | --- |
| GRIT P | 鲜明红、黄绿、清楚的中间调反差 | 鲜活正片 · 清晰层次 | 街头、旅行、晴天 |
| GRIT N | 蓝绿、柔红、柔和高光与较深色彩 | 蓝绿负片 · 复古日常 | 城市、绿植、日常记录 |
| SKIN C | 暖而明亮的肤色、柔和反差 | 暖调人像 · 柔和肤色 | 人像、室内、咖啡馆 |
| CC | 克制饱和、沉稳蓝色、清晰层次 | 低饱和纪实 · 沉稳蓝调 | 建筑、旅行、阴天 |
| NC | 与 GRIT N 拉开：暖亮部、较浓绿、胶片反差 | 浓郁负片 · 怀旧色彩 | 生活、街拍、夕阳 |
| M-RF | 较浓红色、暖肤色、厚实反差 | 浓郁红调 · 经典街拍 | 街头、人文 |
| V-MF | 平滑高光、自然肤色、细腻色彩 | 细腻色彩 · 柔和高光 | 人像、风景 |
| ORIG | 原图直出，不叠加风格处理 | 原图直出 · 自然记录 | 对照、日常 |

## 双列卡片的信息层级

建议为每张卡片依次呈现：有辨识度的视觉图形或真实风格样片、相机名称、一行审美特点、推荐光圈。主题色可作为识别辅助，不能承担展示全部成片效果的任务。此布局是针对用户需求提出的设计，尚未直接检查竞争产品当前选择器布局。

推荐光圈来自现有 profile 的 `aperture.preferred`，以「推荐 ƒ/2.8」等文字说明；当前光圈与是否支持物理调节来自真实硬件能力，避免把推荐值宣传为所有设备的实际光圈。固定光圈设备保留诚实的固定光圈 / DEMO 说明。ORIG 若没有推荐值，不应凭空指定。

## 校准与验收

使用相同输入的肤色、绿植、蓝天、红色物体、室内暖光和高反差照片检查：GRIT N 与 ORIG 应可快速区分；GRIT P 与 GRIT N 在红绿蓝上均有分工；SKIN C 和 V-MF 保留可信肤色；高光不出现明显色块、暗部不大片堵死。颗粒、暗角与光晕只作辅助，不以模糊人脸制造特色。预览与成片仍共用现有渲染器。参数、UI 与效果的最终验收均需真机拍摄，本报告不代表已经完成真机校准。
