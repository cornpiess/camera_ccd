# 服务端接口与数据结构说明

全部来自反编译代码与 dex 字符串（见同目录 `dex内_API与AILook字符串全集.txt`）。
未抓包、未访问服务器；以下为客户端代码可证明的 schema。

## 1. 接口（Retrofit 端点字符串）

| 端点 | 作用（推断自调用方） |
|---|---|
| `v1/api/look/class/get` | Look 分类列表（`AILookCategoryRes`） |
| `v1/api/look/get/basic` | Look 基础列表（`AILookListRes`：id/sort/groupId/hotSort/type） |
| `v1/api/look/get/info` | Look 详情（`AILookInfoRes`：**name**、icon_uri_path、phone_icon_uri_path、type、group_id、hot_sort、is_hot/is_new、CreatedAt/UpdatedAt） |
| `AILookMetaRes.url_prefix`（"url_prefix" 字段） | CDN 前缀，拼接素材下载 URL |

调用方：`PresetRepositoryImpl.fetchAILooks` / `fetchCameraLookItemsInternal` /
`persistCameraLookData`（写 Room `material` 表）。

## 2. 素材包（一个相机色彩 = 一个包）

下载器：`CameraLookPreloader`（编辑页）、`CameraXServiceProvider.triggerCameraColorMaterialEntityFetchOrDownload`（相机页）。
Room 表 `material`（字段示例：material_type, group_id, entity_id, download_url, state…），type=CAMERALOOK。

包内结构（native 路径字符串证据）：

```
CameraLook/CSxxxxx/
├── config.json            ← 加密；含 profiles 列表（RAW/Non_Raw × 设备 × 场景）
│                            "missing default profile Non_Raw+Other" 为兜底
├── aitoning/
│   ├── jsonbuffer.json    ← AIToning 参数（flatbuffer raw_param_list 的 JSON 面）
│   ├── lowbits.png        ← 16-bit LUT 低 8 位（native FilmCache cols/rows）
│   ├── highbits.png       ← 16-bit LUT 高 8 位
│   ├── rawbits.bin        ← RAW 路径附加数据
│   └── profile            ← Profile 元数据
└── preview_cubes/         ← 相机页实时预览 LUT（缺失时报 "legacy package"）
palette512Image（512×512 = 64³ 2D 打包 LUT，palette512ImageMD5 校验）
```

## 3. 运行时数据结构（客户端仅存 ID + 强度）

```kotlin
// 效果值（存入工程 effect 表 ext_used_camera_color_material_id / ext_ai_look 等）
CameraLookModel(id: String /* "CS00002" */, amount: Float)

// Recipe（APK 内置示例 140501）
CameraRecipeParams(
  color: CameraRecipeParamId(id=140352),   // → CameraLook/CS00002
  portrait: ...{id=140401}, lightning: {id=1}, lensBlur: {id=0},
  longExposure: {id=1}, correction: {id=0}, qualityEnhance: {id=0}
)
CameraRecipeSettings(aspectRatio: Int)

// 内置 ID → 包编码映射（CameraRecipeColorLegacyResolver）
140351→CS00001 … 140357→CS00007, 140358→CS00010, 140359→CS00009, 140360→CS00011
（注意：CS00008 缺号；无 140361+，更多相机全靠云端）
```

## 4. 参数 bucket（native 侧，不复制数值）

- Look 的全局参数以 **零点偏移表** 形式存储：`allAILookZeroOffsetGlobalParams`，按
  `cctKey`（色温桶）/ `tintKey`（色调桶）索引 → 运行时按每图估计的 CCT/tint 取增量。
- 参数集含（符号级）：ToneCurve(PV2012 per-channel)、HSLTunner{Hue,Sat,Luma}×8 色、
  HueSatMap、ColorGrade{Global/Highlights/Midtones/Shadows}×{Hue,Sat,Lum}、
  SplitToning{Highlight,Shadow}×{Hue,Sat,Balance}、Vibrance、Monochrome/BleachBypass。
- 开关：`CameraLook autoWB / autoExposure`（可 discard）。
