# 像素蛋糕「相机模拟」实现分析报告

来源：com.xiangtian.pixcake.apk（解包 + jadx 反编译 + native 字符串分析）。
所有结论标注 [CONFIRMED] / [LIKELY] / [UNKNOWN]。未导出任何商业 LUT/参数数据。

## 1. 核心结论

1. [CONFIRMED] 相机模拟 UI 卡片是 `CameraRecipe`（组合包）：color（相机色彩核心）+ portrait + lightning + lensBlur + longExposure + correction + qualityEnhance。
2. [CONFIRMED] 用户看到的 24+ 个相机名（富士C200/柯达5219/徕卡M9…）**不在 APK 内**，由服务器接口下发（v1/api/look/*），每个是一个可下载 Material 包（type=CAMERALOOK，带 url/md5/version）。日志字符串 "camera_color DB empty; UI shows empty list until next fetchAILooks" 证明。
3. [CONFIRMED] 内置映射：色彩 ID 140351–140360 → `CameraLook/CS00001…CS00011`（共 10 个，CS00008 缺号）。II 代（CC II/哈苏蓝 II）为独立包/编码。
4. [CONFIRMED] Look 包结构（native 路径字符串）：`config.json`（加密）+ `aitoning/{jsonbuffer.json, lowbits.png, highbits.png, rawbits.bin, profile}` + palette512Image + preview_cubes。lowbits+highbits 双 PNG = 16-bit LUT（native: `m_pFilmCache->cols/rows, rawHighBitsData/rawLowBitsData`）。
5. [CONFIRMED] 一个 Look 内含**多个 Profile**，按 RAW/Non_Raw × 拍摄设备 × 图像选择（"missing default profile Non_Raw+Other"、"no matching profile for %s"、"using default profile (Non_Raw + Other) for: %s, camera: %s, image: %s"）。
6. [CONFIRMED] 动态适配存在且为**本地规则**：引擎先对每图做 WB 校准（`Param CCT: init/abs/rel`、`temperature_n/temperature_p/tint_n/tint_p/tint_std`），Look 的 `ZeroOffsetGlobalParams` 按 `cctKey/tintKey` 分桶，运行时取增量曝光/WB（`CameraLook autoWB/autoExposure: true, discard:`）。
7. [CONFIRMED] 统一渲染引擎：Meitu PixCook native（OpenCL+GLSL）。Look 展开为 AIToningData flatbuffer（raw_param_list）：ToneCurve、HSL/HueSatMap、ColorGrading(H/M/S)、SplitToning、Vibrance、ColorMatchOpacity。
8. [LIKELY] 设备适配：native 内嵌数百个按摄像头型号命名的 "3DLUT-Strand"（iPhone14,2 back camera、LEICA M10-P 等），用于先归一设备色彩再套 Look——也是「iPhone珠光」类 Look 的技术基础。
9. [CONFIRMED] 相机页实时预览是简化管线：CubeLutRenderer（.cube，LUT_3D_SIZE）+ PngLutRenderer（2D 打包 PNG，64³/512×512）+ intensity 混合；拍后切 `postCaptureLutPath` 走完整 native 管线。
10. [CONFIRMED] AI 参与 = Look 分类/推荐/AIColorMatch（上传图配色），**不是**逐图色彩推理；逐图适配是数值规则。包内参数全部预生成。

## 2. Q1–Q12 快答

- **Q1 多少个相机模拟**：APK 内置 Recipe 5 个、内置色彩编码 10 个；线上完整列表服务器下发（你列的 24 个均在此，[CONFIRMED] 机制 / 数量以服务端为准）。
- **Q2 组成**：16-bit LUT + 参数 Profile（ToneCurve/HSL/ColorGrading/SplitToning）+ CCT/tint 分桶偏移表 + autoWB/autoExposure 开关 + 预览用 palette512/preview_cubes。
- **Q3 一台相机=一张 LUT 吗**：不是——一个包含主 LUT + 预览 LUT + 多 Profile。[CONFIRMED]
- **Q4 多 LUT**：是（主 + 预览 + 各 Profile）。[CONFIRMED]
- **Q5 共享**：引擎/管线全共享；LUT 本体按相机独立；设备归一化 3DLUT-Strand 跨相机共享。[LIKELY]
- **Q6 ToneCurve/HSL 属于 Recipe 吗**：属于 Look 包内参数（AIToningData raw_param_list）。[CONFIRMED]
- **Q7 动态变化**：曝光/WB 增量逐图变化。[CONFIRMED]
- **Q8 谁计算**：本地规则算法。[CONFIRMED]
- **Q9 肤色保护**：引擎存在 SkinAdjust/SkinTone 系列效果与 skinMask 机制，但未见证据表明 Look 必带肤色保护 [UNKNOWN→LIKELY 有]。
- **Q10 Grain/暗角/Bloom/Halation**：RealGrain 是独立效果（单独配置+滑杆），非 Look 必带；未发现 Halation 符号。[CONFIRMED 排除多数]
- **Q11 差异来源排序**：LUT > Tone/HSL/ColorGrading 参数 > 动态曝光/WB > 纹理（Grain）。
- **Q12 底层架构**：类型 C/D —— 统一引擎 + Look 数据包（LUT+参数 Profile）+ 本地动态校正；新增相机 = 传数据包，客户端零代码。

## 3. 主链路

```
CameraRecipe.json (UI)
→ recipe.id / color.id
→ CameraRecipeColorLegacyResolver → CameraLook/CSxxxxx
→ MaterialEntity(type=CAMERALOOK, url, md5, version)   [Room DB]
→ v1/api/look/get/basic + get/info；下载至本地缓存
→ 解密 config.json；ensurePackageLoaded
→ nativeSetCameraLookIDWithApply(id, amount)
→ PixCook: Profile 选择 → autoWB/autoExposure 增量(cctKey/tintKey)
   → ToneCurve → HSL → ColorGrading → SplitToning → 16bit LUT → ColorMatchOpacity
→ 输出
```

## 4. 我们的 iPhone 方案（详见 06_我们的Swift实现）
