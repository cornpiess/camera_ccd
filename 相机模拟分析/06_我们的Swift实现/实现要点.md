# 实现要点（从逆向分析推导的决策清单）

## 为什么不需要像素蛋糕的全套复杂度

| 像素蛋糕 | 原因 | 我们 |
|---|---|---|
| 16-bit 双 PNG LUT（lowbits+highbits） | 高光/暗部不banding，导出级精度 | 导出 64³ 8bit 起步，观感不足再上 16bit |
| RAW/Non_Raw × 设备 Profile | 安卓设备色彩差异巨大 | iPhone 色彩一致性高，1–3 个 Profile 足够（前置/后置） |
| per-device 3DLUT-Strand 归一 | 同上 | 不需要；仅在苹果 ProRaw 直出与标准 sRGB 间做一次归一 |
| AI Look 推荐/云配色 | 商业产品运营功能 | 不需要 |
| 服务器下发 Look 包 | 商业更新节奏 | 8 台英雄相机直接打进 bundle（每台 ~几百KB） |

## 必须抄对的三件事（主观效果的来源）

1. **LUT 放在曝光/WB 增量之后**（先归一，再上风格）——顺序错了会"偏色上偏色"。
2. **CCT/tint 分桶自适应**——这是"任何照片套上都好看"的关键，占主观效果 ~20%。
   每台相机手调 4–5 个色温桶（3000/4300/5500/6500/8000K）的增量 EV/WB。
3. **强度混合 intensity**——所有参数整体可调（对齐其 GLSL `mix(original, lut, intensity)`），
   UI 上一个滑杆控制整个 Look，而不是逐参数暴露。

## 建议优先级

1. P0：单 pass Metal kernel：3D LUT + tone curve + HSL（合并查表，一帧一 kernel）。
2. P0：CCT 估计（先用 AVCaptureDevice whiteBalanceGains，成本为零）+ 分桶插值。
3. P1：肤色回退 mask（肤色椭圆域 + 饱和度/亮度范围，LUT 前后 mix 20–30%）。
4. P1：预览 33³ / 导出 64³ 双档（对齐其 palette512/preview_cubes 分离）。
5. P2：Grain（黑白机型）与 Vignette（个别机型）。

## 数据校准流程建议

每台英雄相机：
1. 用真实样片（或该相机官方 JPEG 样片集）与 iPhone 直出做 3D LUT 拟合（HaldCLUT 法）；
2. 拟合出的 LUT 载入后，对 5 个色温档的标准色卡图微调增量 EV/WB，填 AdaptiveConfig；
3. 肉眼 A/B 迭代 ToneCurve/HSL，直到主观 80–90% 接近。
