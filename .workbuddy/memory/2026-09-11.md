### 关键技术决策（均已查证，非推测）
- **`ExportOptions.plist` 的 `method` 值随 Xcode 改过名**（Apple DTS 论坛 773749 确认）：Xcode 16 起
  `app-store` → **`app-store-connect`**、`ad-hoc` → `release-testing`、`development` → `debugging`；旧名仍作 deprecated 别名可用。
  → 新的 testflight workflow 按 `xcodebuild -version` 主版本自动选。`ios-dev-build.yml` 里仍写死 `ad-hoc`（别名，目前能用），值得后续一起改成动态。
- **Apple 自 2026 年起要求上传 ASC 的 iOS 包必须用 Xcode 16+ 构建** → 已写进 preflight，低于 16 直接硬失败（省 30 分钟）。
- **`expo-dev-client` 不会污染 Release 包**：官方 README 明确「Release builds … will not change other than the addition of a few header files」，
  Expo PR #16190 测试计划也写了「release build does not have the dev client」。仍加了一条断言：app 内必须存在 `*.jsbundle`，否则白屏。
- **上传两条路**：优先 `xcrun altool --upload-app`（deprecated 但 Xcode 16/26 仍可用，日志清晰），失败回退
  `xcodebuild -exportArchive` + `destination=upload`（Apple 原生通道，不依赖 altool 存活）。
- **build number 用 `github.run_number`**：ASC 要求严格递增，否则拒收；由 `app.config.js` 注入。
- **`manageAppVersionAndBuildNumber: false`**：不让 Xcode 自己改版本号，保持确定性。
